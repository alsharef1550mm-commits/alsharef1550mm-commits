## 🚀 Featured project

### [🏛️ AI Audit System for Government Tender Documents](https://github.com/alsharef1550mm-commits/gov-tender-docs-audit-ai)

An end-to-end system that audits **every** receipt in a tender payment bundle instead of a sample.

| | |
|---|---|
| 👁️ **Document AI** | Text layer, OCR (Tesseract) and a vision-language model (Qwen3.5-9B on vLLM) for scanned pages |
| 🧮 **Accounting engine** | Commission, VAT and late-penalty rules read from each contract, computed with exact `Decimal` arithmetic |
| 🔗 **Three-way matching** | Purchase order ↔ receipt ↔ invoice at line level, including shared invoices and duplicate receipts |
| 🧪 **Safety gate** | Deterministic checks accept a reading or refer it to a human reviewer with page evidence |
| 🎛️ **Fine-tuning** | LoRA on a 9B vision-language model, measured honestly against prompt design |
| 📊 **Reporting** | Locked Excel templates, an Arabic review app (Gradio) and a page-orientation tool |

**Results on synthetic data:** 7,249 / 7,249 receipts matched with zero differences · 10 / 10 planted errors detected · 0 errors passed without referral.

[🚀 Live demo](https://huggingface.co/spaces/abade1990/audit-review-private) · [📂 Code](https://github.com/alsharef1550mm-commits/gov-tender-docs-audit-ai)
